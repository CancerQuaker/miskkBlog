# 主题色星空闪烁设计

## 目标
用随机分布、忽明忽暗的四角星营造漫天星空氛围，不再使用飘落轨迹；随主题色变化且不干扰阅读。

## 方案
采用固定百分比坐标 + CSS opacity 动画。每颗星拥有独立尺寸、峰值透明度、闪烁周期和负延迟，避免整齐同步；不再运行 JavaScript rAF 循环。

## 设计参数
- 默认 48 颗，12–22px，峰值透明度 0.18–0.42。
- 主形状 `var(--primary)`，高光 `var(--primary-light)`，SVG 颜色写入 `style`。
- 坐标随机分布于视口，周期 2.4–5.6 秒，负延迟错开相位；只改变透明度，不改变位置。
- 保留开关、窄屏禁用和 `pointer-events: none`；减少动态效果偏好下静态显示。
- 可见文案统一为“星空氛围 / 漫天星星随机闪烁”，内部组件名与存储键保留以避免无关迁移。

## 验证
先验证数量、坐标范围、主题变量、动画参数和不调用 rAF，再验证清理重开、完整构建及不同主题下的实际星空效果。
