# 主题色星空闪烁设计

## 目标
用随机出现、忽明忽暗的四角星营造漫天星空氛围，不采用飘落轨迹，也不让星星永久固定在同一坐标；随主题色变化且不干扰阅读。

## 方案
复用首页横幅 `.hero-star` 的 CSS 四角星轮廓与 `starTwinkle` 动画。每颗星在动画回到最暗的迭代边界时，通过 `animationiteration` 更新随机百分比坐标，从下一轮开始在新位置闪烁，不使用 rAF 或定时器。

## 设计参数
- 默认 48 颗，12–22px，背景使用 `var(--primary)`。
- 轮廓使用横幅同款 `clip-path`；2.6 秒 `starTwinkle`：透明度 0.25–0.85，缩放 0.7–1.15，旋转 0–45°。
- 星空层以 `body` 为定位容器，使用 `position: absolute; inset: 0` 覆盖整页并随文档滚动；坐标按整页高度计算。
- 初始位置随机，负延迟错开相位，每轮结束重新随机位置；位置切换发生在最低透明度时刻。
- 保留开关、窄屏禁用和 `pointer-events: none`；减少动态效果偏好下静态显示，不触发换位。
- 清理时同时移除 `animationiteration` 监听和节点。

## 验证
验证 48 颗、尺寸与周期、主题色、迭代后坐标改变、监听与节点清理、零 rAF，再运行构建并检查实际页面。
