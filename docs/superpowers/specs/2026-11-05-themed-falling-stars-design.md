# 主题色星空闪烁设计

## 目标
用随机分布、忽明忽暗的四角星营造漫天星空氛围，不再使用飘落轨迹；随主题色变化且不干扰阅读。

## 方案
采用固定百分比坐标，并直接复用首页横幅 `.hero-star` 的 CSS 四角星轮廓与 `starTwinkle` 动画。每颗星仅尺寸和负延迟不同，位置保持固定，不再运行 JavaScript rAF 循环。

## 设计参数
- 默认 48 颗，12–22px，背景使用 `var(--primary)`。
- 轮廓使用横幅同款 `clip-path: polygon(50% 0, 62% 38%, 100% 50%, 62% 62%, 50% 100%, 38% 62%, 0 50%, 38% 38%)`。
- 复用横幅 2.6 秒 `starTwinkle`：透明度 0.25–0.85，缩放 0.7–1.15，旋转 0–45°。
- 随机负延迟错开相位；保留开关、窄屏禁用和 `pointer-events: none`。
- 减少动态效果偏好下静态显示；可见文案统一为“星空氛围 / 漫天星星随机闪烁”。

## 验证
验证 48 颗、坐标和尺寸范围、2.6 秒周期、CSS 轮廓与关键帧复用、零 rAF 和清理，再运行构建并对照首页横幅检查实际效果。
