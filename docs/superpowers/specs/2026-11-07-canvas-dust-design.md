# Canvas 固定区域柔光尘设计（当前实现）

> **状态：现行设计。** 本文对应 `frontend/src/components/SakuraEffect.tsx` 的当前代码。组件名与 `sakura` 开关名为历史遗留，实际效果已不再是樱花或星空。

## 核心行为

- 使用全屏 Canvas，默认固定 **128 个柔光粒子**并随机分布；交互过程中不会新增、删除或自动补充。
- 每个粒子拥有独立的固定椭圆运动区域。环境漂浮、鼠标牵引和粒子互斥完成后，统一将位置约束回各自区域。
- 鼠标位于页面背景或留白时，从当前牵引粒子与环境粒子中选择**距离最近的 16 个**；鼠标每次移动都会重新按实时距离排序。
- 鼠标位于卡片、导航栏、横幅、页脚或浮层时不启动牵引，粒子保持环境漂浮。
- 被释放的粒子恢复环境模式并返回自己的区域，不生成替代粒子。

## 固定区域

- 区域横向半径初始为 `48–90px`，纵向半径为 `36–66px`；避让卡片多次失败时可缩至 65%。区域创建后固定，窗口或卡片布局变化时重新初始化。
- 区域中心采用随机分布：左侧非卡片区域与右侧非卡片区域各占约 45%，中央卡片区域约占 10%。左右仅保持概率上的均衡，不保证每次初始化的实际数量完全一致。
- 非中央候选最多进行 24 次随机采样，通过真实卡片矩形检测尽量避免整个椭圆与卡片相交；后 12 次采样将区域半径缩小至 65%，仍失败时保留相交卡片数最少的候选。中央候选直接放行，因此卡片区域只保留少量点缀。
- 使用 `MutationObserver` 监听卡片增删，防抖 200ms 后重新计算分布，覆盖异步文章挂载与路由切换；日常漂浮和牵引过程中不重建粒子。
- 使用椭圆归一化距离约束：若 `(dx / radiusX, dy / radiusY)` 的长度大于 1，则将两个位移分量同时除以该长度，投影回边界。
- 鼠标只能将粒子吸到自身区域边缘，不能将粒子带入其他区域。

## 牵引与连线

- 牵引候选数量固定为 16，距离更远的当前候选会被更近的环境粒子替换。
- 鼠标与每个被牵引粒子之间绘制 `0.7px` 细线，透明度随牵引强度变化。
- 被牵引粒子之间距离小于 `110px` 时绘制 `0.55px` 邻近连线；距离越近越清晰。
- 普通环境粒子不绘制鼠标连线，也不参与牵引连线。

## 粒子互斥

- 仅被牵引粒子参与互斥，互斥范围为 `36px`，强度常量为 `1.4`。
- 距离越近，对称分离位移越明显，用于减少粒子重叠和连线挤成一团。
- 互斥计算后仍执行固定区域约束，因此增强互斥不会把粒子推出自己的区域。

## 外观与生命周期

- 粒子直径约 `2–5px`，使用主题主色和浅端色绘制柔光，不绘制星星、花瓣、双圈或牵引范围线。
- Canvas 使用 `pointer-events: none`，不会阻挡卡片点击、文本选择或鼠标指针事件。
- 主题色变化通过观察根元素的 `data-theme` 与行内样式同步更新。
- 窄屏（小于 768px）不启用；系统开启“减少动态效果”时只绘制静态环境粒子。
- 关闭“微光氛围”开关时清空画布并移除全部事件监听；重新开启后按默认数量初始化。

## 明确取消的旧行为

- 不再有樱花飘落、四角星闪烁、整页随机换位。
- 不再有内外双圈、鼠标内圈斥力或环带专属牵引。
- 不再自动补充空缺粒子，也不再将旧粒子标记为退出后删除。

## 验证要点

- 前端执行 `npm run build`，通过 TypeScript 与 Vite 构建。
- 浏览器确认：粒子总数始终为 128，背景牵引数为 16，卡片区域释放为 0；在不同视口和卡片完整渲染后，卡片中心与椭圆相交比例均显著低于旧算法，且中央仍有少量粒子。
- 检查牵引和互斥后粒子的椭圆归一化距离不超过 1，释放后返回原区域。
- 检查鼠标连线、粒子邻近连线、主题切换、开关清理和减少动态效果模式。
